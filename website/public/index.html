WHY THIS EXISTS

The block is real. So is the way around it.

Myanmar's networks filter traffic with DPI (Deep Packet Inspection). Sites, apps and whole services disappear — sometimes for days. WARP Connect doesn't pretend the block isn't there: it finds which WARP endpoints still pass, proves one is really carrying data, and keeps that connection alive.

WHAT HAPPENS WHEN YOU TAP CONNECT

01

Registers once

A throwaway WARP account is created on first run — through the API, a relay, or an in-tunnel registration. It's yours forever; no email, no phone number.

02

Picks a working endpoint

Remembered per-network winners are tried first; otherwise the app scans Cloudflare's WARP endpoints and keeps the ones that survive in-tunnel tests — validated with a real handshake and a data-crossing check.

03

Stays connected

If the tunnel is torn down by the network, the app notices within seconds and reconnects — usually to an endpoint that already worked on this exact network.

PRIVACY, STRAIGHT

No theatre. Here is exactly what leaves your phone.

  • Connection telemetry — endpoint, carrier (ATOM/…), ASN, city/country. That's all. No browsing history, no messages, no passwords, no identity.
  • Crash and usage events — Firebase Crashlytics + Analytics, so failures get fixed.
  • Your WARP account — a throwaway device identity in app-private storage. Never rotated, never linked to you.
  • Open source — every line is in the repo. No hidden SDKs beyond Firebase and nothing else.

HONEST ANSWERS

Questions people actually ask

Why not Google Play?

Because Play sits behind the same filter, and sideloading is how everyone in Myanmar installs this class of app today. Updates come from the Releases page. Play Protect will warn you — that's expected for any sideloaded app, not a verdict.

Why does the first connect take minutes?

Registration, then a scan of WARP endpoints, then verification of each survivor — that's real work on a filtered line. Every later connect reuses the per-network cache and usually wins in seconds.

Does it work on MPT / Ooredoo / Mytel?

It's developed and tested on ATOM. The endpoint engine is generic and the other carriers use the same Cloudflare backbone, but success is best-effort — if a network blocks every WARP endpoint, no app can make it work.

How do I update?

Download the new APK from the Releases page and install it over the old one. The signature is the same, so it upgrades in place. Your account survives.

Is it free?

Yes. No ads, no upsell, no in-app purchases. Built by one person for one market.

ဘာလို့ Google Play မှာမတင်ထားတာလဲ?

Play ကလည်း filter အောက်မှာရှိလို့ပါ။ Myanmar မှာ APK နည်းနဲ့ တပ်ဆင်တာက ယနေ့အတွက် ပုံမှန်ပါ။ Update တွေက Releases page ကနေ download လုပ်ရပါတယ်။ Play Protect သတိပေးတာက ပုံမှန်ပါ — sideloaded app မဆို သတိပေးပါတယ်။

ပထမဆုံး ချိတ်ဆက်မှု ဘာလို့ ကြာတာလဲ?

Account တည်ဆောက်၊ endpoint တွေ စကန်စစ်၊ ချိတ်ဆက်နိုင်တာတွေကို စမ်းသပ် — အလုပ်နဲ့ အချိန်ပေးရပါတယ်။ နောက်ပိုင်း ချိတ်ဆက်မှုတွေကတော့ network cache ကြောင့် စက္ကန့်ပိုင်းနဲ့ ရပါတယ်။

MPT / Ooredoo / Mytel မှာ အလုပ်လုပ်လား?

ATOM ပေါ်မှာ develop နှင့် စမ်းသပ်ထားပါတယ်။ MPT, Ooredoo, Mytel မှာလည်း Cloudflare backbone တူတာကြောင့် အလုပ်လုပ်နိုင်ပါတယ် — ဒါပေမယ့် WARP endpoint အားလုံးကို block လုပ်ထားတဲ့ network မှာတော့ ဘယ် app မှ မလုပ်နိုင်ပါဘူး။

Update ဘယ်လိုလုပ်ရမလဲ?

Releases page က APK အသစ်ကို download ပြီး ဟောင်းပေါ်မှာ ထပ် install လုပ်ပါ။ Signature တူတဲ့အတွက် သာမာန် install ရပါတယ်။ Account မပျောက်ပါဘူး။
